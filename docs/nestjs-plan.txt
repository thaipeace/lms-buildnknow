# Tuần 4 — Authentication & Authorization

Phần này rất quan trọng với bạn vì trước đây bạn đã làm JWT.

Không chỉ học:

```text
JWT → Guard → User
```

Mà phải hiểu:

```text
Authentication
      ↓
Authorization
      ↓
Guard
      ↓
ExecutionContext
      ↓
Custom decorator
      ↓
Role / Permission
```

Làm:

```text
User
Role
Permission
```

Ví dụ:

```text
ADMIN
 ├── user.read
 ├── user.write
 └── user.delete

STAFF
 ├── user.read
 └── user.write
```

Sau đó làm:

```text
@Roles('ADMIN')
@Permissions('user.delete')
```
